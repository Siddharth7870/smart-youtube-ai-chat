#  🎥 Smart YouTube Clone with AI Chat Assistant

A clone of YouTube with an integrated AI Chat feature — built for the **Level Up: Vibe Coding Hackathon 2025**.

## 🎯 Features

-**AI Chat Assistant**: Ask questions while watching videos
-  Real-time video suggestions from chat queries
-  AI-powered video summaries and search help
-  Chat UI that blends with YouTube interface
-  Smooth and responsive web app
